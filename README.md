# PRODIGY

[Kasuta mootori kalkulaatorit brauseris](https://johanneslink777.github.io/pythoni_kalkulaator/).

Veebiversioonis on 39 üldist mootoriprofiili. Vali profiil ja muuda kubatuuri, pöördeid ning sisselaskeõhu temperatuuri näidikul või liuguril. Liugureid saad juhtida ka nooleklahvidega. Õhuvool, kütusekulu, võimsus ja väändemoment arvutatakse jooksvalt. Tulemused on lihtsustatud mudeli hinnangud.

Veebiversiooni failid asuvad kaustas `docs/`. GitHub Pagesi avaldamisallikas on haru `main` ja kaust `/docs`.

Töölauaversiooni käivitamise juhised on failis [LOE_MIND.txt](LOE_MIND.txt). Arvutuse eeldused ja mootoriprofiilide allikad on failis [MOOTORITE_ALLIKAD.md](MOOTORITE_ALLIKAD.md).
